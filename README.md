# 🚦 馬太鞍溪防災積木元件系統

**韌隊 — 防災積木元件創新賽 2025**
**花蓮馬太鞍溪堰塞湖情境**

> 以模組化「積木」概念設計的防災數位工具，整合路燈警示、逃生路徑、安全回報與 AI 影像辨識，每個元件均可獨立使用，也可彼此拼接串聯。支援手機與桌機，全程單一 HTML 檔案，無需安裝。

🌐 **線上展示**：https://sylviia-su.github.io/mataaan-disaster-system/

---

## 📋 專案說明

本系統以 2025 年 9 月花蓮馬太鞍溪堰塞湖事件為設計情境，針對花蓮光復鄉的地理環境與族群特性，開發一套可模組化部署的防災數位工具。

### 核心設計理念

```
民眾回報（Call）  →  AI 解析  →  標準化 JSON
                                      ↓
應變中心分析（Analysis）  →  路燈控制 / 逃生路徑更新 / 資源調度
```

每個元件的輸入與輸出均採標準化 JSON，可獨立運作，也可與其他防災系統串接。

## ✨ 功能模組（7 個頁籤）

### 👥 使用者流程（第一頁）
- **主流程**：一般居民（林小姐）從接收警報到資料同步的完整 6 步驟
- **例外路徑**：
  - 👴 獨居老人（陳阿公）：路燈閃光 → 語音電話（台語）→ 按鍵求助 → 志工接送
  - 🦺 志工協調員（王大偉）：登記資源 → AI 任務媒合 → 循環執行
  - 🏛️ 應變中心（林佳慧）：感測觸發 → 人工審核 → 多管道發布 → AI 警示偵測
- **差異對照表**：4 個 Persona × 4 個比較維度

### 🚦 路燈警示控制（Call + Analysis）
- 四級警戒對應燈色：
  - 🔵 監控中（2025-07-26）：藍色常亮
  - 🟡 黃色警戒（2025-08-12）：黃色慢閃
  - 🔴 紅色警戒（2025-09-22）：紅色快閃
  - 🚨 潰壩溢流（2025-09-23）：紅色極速閃
- **雙模式控制**：
  - 系統自動觸發 → 進入待人工確認佇列 → 值班人員核准/拒絕
  - 人工直接控制：選擇路燈、燈色、閃爍速度，立即套用
- 收容所路燈特殊邏輯（紅色警戒時自動轉綠色常亮）
- Demo 時間軸播放功能

### 🗺️ 逃生路徑（Analysis）
- **即時定位**：自動找出距離最近的政府指定收容所，OpenStreetMap 地圖顯示
- **預先設定路線**：
  - 🏠 家裡路線：設定家庭地址、指定收容所、備用路線
  - 🏢 公司/公共區域路線：設定管理單位、逃生出口
- **AI 動態路由修正**：分析路況，標示危險路段，自動建議替代路線
- 地圖標記三個政府指定收容所（光榮國小、光復國中、太巴塱國小）

### 🆘 安全回報（Call）
- 四種狀態：✅ 安全 / 🤕 受傷 / 🆘 受困 / 👥 代報他人
- **SALT-inspired 急救分級評估**（受傷/受困時顯示）：
  - ① 意識狀況（清醒 / 混亂 / 有反應 / 無反應）
  - ② 有無外傷（無 / 輕微 / 持續出血 / 骨折 / 頭頸部 / 夾壓）
  - ③ 可否自行移動（步行 / 攙扶 / 擔架 / 完全不能動）
  - ④ 呼吸狀況（正常 / 費力 / 無呼吸）
  - 自動判斷傷患分級（即時搶救 / 延遲處理 / 輕傷）
- 姓名選填（支援匿名回報）
- GPS + 地址並行輸入（兼顧花東偏遠地區）
- **居民回報地圖**：送出後即時標記於 OpenStreetMap，待情資中心審核後正式顯示

### 🤖 AI 影像辨識（Call + Analysis）
- 照片上傳（支援手機相機直接拍攝）
- Claude Vision API 自動判斷：災害類型、嚴重程度、積水深度、通行建議
- AI 分析結果自動帶回人工輸入欄位，可直接修改
- **人工輸入模式**（不需上傳照片）：
  - 手動輸入地址 + GPS 定位並行
  - 下拉選單選擇災害類型與嚴重程度
  - 補充說明文字框
- 輸出標準化 JSON，可標註至 OpenStreetMap 防災地圖
- ⚠️ 免責聲明：AI 可能會出錯，請謹慎查核使用

### 📊 監測資料
- 馬太鞍溪水位趨勢圖（含 1139m 警戒水位線）
- 花蓮光復雨量趨勢圖
- NCDR 堰塞湖監測頁嵌入（國家災害防救科技中心）
- 以上圖表為模擬重建數據，僅供展示

## 🖥️ 技術架構

```
使用者裝置（手機 / 電腦）
      ↓
index.html（單頁應用，RWD）
      ├── Leaflet.js（OpenStreetMap 地圖）
      ├── Chart.js（水位雨量圖表）
      └── Claude API（AI 影像辨識）

Flask 後端 API（選用）
      └── 模擬路燈控制器（NB-IoT 介面預留）
```

| 項目 | 技術 |
|------|------|
| 前端 | 純 HTML / CSS / JavaScript（無框架） |
| 地圖 | Leaflet.js + OpenStreetMap（免費） |
| 圖表 | Chart.js |
| AI 影像辨識 | Anthropic Claude Vision API |
| 後端（選用） | Python Flask |

## 🚀 啟動方式

### 前端（直接開啟，無需伺服器）

```bash
open frontend/index.html
# 或直接用瀏覽器開啟，支援手機與桌機
```

> ⚠️ AI 影像辨識需要 Anthropic API 金鑰。其餘功能（地圖、逃生路徑、安全回報、路燈控制）均可完全離線使用。

### 後端（選用）

```bash
cd backend
pip install -r requirements.txt --break-system-packages
python app.py
# API 運行於 http://localhost:5000
```

## 📡 後端 API

| 方法 | 路徑 | 說明 |
|------|------|------|
| `GET` | `/api/status` | 系統狀態摘要 |
| `GET` | `/api/lights` | 所有路燈狀態 |
| `POST` | `/api/alert` | 觸發警戒等級 |
| `POST` | `/api/alert/clear` | 解除警報 |
| `GET` | `/api/logs` | 警報紀錄 |
| `POST` | `/api/demo/replay` | 播放時間軸 Demo |

**觸發警報範例**

```json
POST /api/alert
{
  "level": "red",
  "area_ids": ["SL-001", "SL-002"],
  "event_id": "E2025-091801",
  "message": "馬太鞍溪水位超過警戒線"
}
```

**AI 影像辨識輸出範例**

```json
{
  "hazard_type": "積水",
  "severity": "medium",
  "water_depth_estimate": "約 30-50 公分",
  "description": "道路積水，部分路面不可見",
  "immediate_action": "繞行台 9 線，避免此路段",
  "safe_for_evacuation": false,
  "location": "花蓮縣光復鄉省道193線42公里處",
  "coords": { "lat": "23.638900", "lng": "121.418700" },
  "source": "AI 分析"
}
```

## 🗺️ 積木拼接架構

```
[感測器] ──→ [通報 JSON] ──→ [AI 分析] ──→ [路燈 API]
[民眾回報]       ↑               ↓         [LINE Bot]
[影像上傳] ──────┘         [地圖標記]    [應變中心儀表板]
```

每個元件的輸出均為標準化 JSON，可被任何下游系統讀取串接，完全符合「積木可拼接」設計原則。
